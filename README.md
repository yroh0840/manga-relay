# Manga Relay

漫画のコマを投稿し、リレー形式でつなげていくWebサービスです。
※本リポジトリはMVP検証用のため、一部未整理のコードが含まれています。

## 概要
ユーザーが1コマずつ画像を投稿し、他のユーザーが続きを描いていくことで、
一つの漫画をリレー形式で作っていくことを目的としています。
自由度の高い投稿が可能で、様々な展開を楽しめる設計としています。

## 機能
- 画像投稿
- 一覧表示
- 詳細表示
- 管理機能

## 構成
- app.py → メインアプリ
- templates/ → フロント
- migrations/ → DB管理
- requirements.txt → 依存関係

## 使用技術
- Python（Flask）
- PostgreSQL
- HTML / Tailwind CSS
- Git / GitHub
